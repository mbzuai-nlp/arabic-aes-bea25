
# 📝 ARWI: Arabic Essay Scoring Dataset

This repository contains data and utilities developed for the Arabic Read, Write and Improve project, aimed at studying and evaluating the effect of prompts, error generation, and CEFR-level classification in Arabic Automated Essay Scoring (AES). The dataset supports experiments in writing proficiency assessment, prompt–essay relevance detection, and synthetic data augmentation for NLP tasks.

## 📊 Data Description

### `topics.csv`
- **Columns:** `Topic_ID`, `category`
- **Description:** Contains a set of thematic categories used to group essay prompts. Each row defines a topic ID and its associated domain (e.g., Education, Technology).

### `prompts.csv`
- **Columns:** `Level`, `Arabic Text`, `Translated Text`, `Topic_ID`, `prompt_id`
- **Description:** Lists original Arabic essay prompts along with their English translations and proficiency levels (Beginner, Intermediate, Advanced). Prompts are linked to specific topics via `Topic_ID`.

### `prompts_expansion_GPT.csv`
- **Columns:** `prompt_id`, `expanded_prompt`
- **Description:** Contains GPT-generated expansions of original prompts to simulate prompt elaboration, used in experiments evaluating prompt richness and essay relevance.

### `arwi_original_essays.csv`
- **Columns:** `Document_ID`, `Original_Essay`
- **Description:** A collection of (Error-Free) Synthetic Arabic essays generated by GPT-4o in response to prompts.

### `arwi_gpt_error_essays.csv`
- **Columns:** `Document_ID`, `GPT_Error_Essay`
- **Description:** Contains synthetic essays with grammatical errors introduced by GPT-based error injection.

### `arwi_bert_error_essays.csv`
- **Columns:** `Document_ID`, `controlled_essay`
- **Description:** Contains essays generated or edited using BERT-based methods to simulate controlled CEFR-level error patterns.

### `arwi_cefr_levels.csv`
- **Columns:** `Document_ID`, `CEFR`
- **Description:** Provides the CEFR writing proficiency label (`A1`–`C2`) for each essay, used for training and evaluation in AES tasks.

### 📂 `Data/Splits/`

This subdirectory contains predefined dataset splits for model training, development (validation), and testing. Each file includes a list of `Document_ID`s referencing essays in the main dataset.

#### Files:
- `arwi_train.csv`  
- `arwi_dev.csv`  
- `arwi_test.csv`  

**Columns:**
- `Document_ID`

**Description:**  
These files define the training, development, and test splits used for various experiments, including:
- CEFR level classification
- Prompt–essay relevance evaluation
- Error analysis and model generalization

The `Document_ID`s listed in each file map directly to entries in:
- `arwi_original_essays.csv`
- `arwi_cefr_levels.csv`
- `arwi_gpt_error_essays.csv`
- `arwi_bert_error_essays.csv`

## 🧾 Document ID Convention

All essays across the dataset use a standardised `Document_ID` format:
<pre><code> AR_{language_model}_{topic_id}{prompt_id}_{essay_id}

- `language_model`: Source of the essay (`gpt-4o`)
- `topic_id`: Refers to the topic from `topics.csv`
- `prompt_id`: Refers to the prompt from `prompts.csv`
- `essay_id`: A unique numeric identifier </code></pre>

A utility function to parse `Document_ID` is provided in `Code/utilities.py`


## ✨ Error Injection using GPT

This Code\Errorinjectino_GPT.py presents the **first approach** for generating realistic learner-like errors in Arabic essays using OpenAI's GPT model. 
#### 🚀 How to Run This GPT-Based Error Injection Code

- Ensure that Python version 3.9 or higher is installed on your system, and install all required packages.

- Insert your OpenAI API key directly into the script where indicated.

- Make sure all necessary data files are available in the `Data/` and `Data/Errors_annotation/` folders.

- Be cautious when running the script, as it will append output to the existing file `arwi_gpt_error_essays.csv`.
